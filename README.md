# Confocal-Microscope
Программное обеспечение для конфокального микроскопа. Целью проекта является создать удобное ПО, способное работать с множеством различных устройств по различным протоколам связи. Проект является учебным и не претендует на верность в первой инстанции, а создаётся с целью изучения программирования и электроники
